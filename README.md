# Pitágoras Interactive

Quero fazer um aplicativo interativo para demonstrar que o quadrado da hipotenusa e igual a soma dos quadrados dos catetos. Desenhar os quadrados nas linhas que correspondem ao lados dos triangulo retangulo e a pessoa vai encher cada quadrado com quadrados menores. Este um app educacional para mostrar a formula de maneira intuitiva que foi como Pitágoras realmente descobriu.
